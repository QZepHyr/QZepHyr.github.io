# Zehao Qi

Personal academic website: https://qzephyr.github.io/

This is a static website hosted with GitHub Pages from the `main` branch and repository root. No build step is required.

## Editing

- `index.html`: profile, research interests, publications and education.
- `styles.css`: typography and responsive layout.
- `script.js`: navigation, research details and citation dialogs.
- `assets/`: portrait, research figures, public CV and fonts.

To preview locally, run `python3 -m http.server 8000 --bind 127.0.0.1` and open http://127.0.0.1:8000/.
